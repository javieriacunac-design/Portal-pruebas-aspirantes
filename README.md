# Portal de pruebas para aspirantes — INDIMON SAS

Prueba técnica de selección para **Armador Tubero 1A**.

## Contenido
- **Prueba técnica Armador Tubero 1A — versión digital.html**: prueba cronometrada de 90 minutos en 6 partes (100 puntos). Las preguntas van cifradas y solo se abren con el PIN de inicio que entrega el evaluador. Al terminar, el aspirante envía su código de resultado por WhatsApp.
- **Portal del evaluador — Prueba Tubero 1A (INDIMON).html**: es la misma página; el evaluador entra con su PIN para calificar códigos.
- **cuadernillo/**: versión impresa de la prueba en Word y PDF (Forma A).

## Uso
Abra el archivo HTML en Chrome. No requiere instalación ni internet.

La clave de respuestas, la guía del evaluador y el código fuente **no** se publican en este repositorio.
